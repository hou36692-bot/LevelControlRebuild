# 图像输入

桌面输入支持选择文件、拖拽文件和粘贴剪贴板图片。支持 PNG、JPEG、静态 WebP，每组最多 4 张；单张原文件最多 20 MiB、40 百万像素。客户端自动修正方向、移除元数据，并将最长边缩至 2048 px、每张编码体积缩至 1 MiB 以内。

缩略图按编号展示，可放大、删除或清空。发送后当前组继续用于后续文字和语音；再次添加图片开始新组，未发送的新组可以继续追加。修改或清除仅影响下一次发送，已排队消息使用发送时的副本。图片只在当前客户端会话中保留，重新启动后需重新添加。

文字决定分析、搭建或修改。只发送图片时，助手仅分析图片，不修改世界。参考图用于现有白盒和目录资产的外观、布局近似，不会导入为纹理或生成三维资产；单图中不可见结构和精确尺寸不能视为事实。

处理失败、连接失败或模型不支持图像时，保留输入并显示原因，不丢弃图片后继续执行。处理中的批次可取消；原图始终不修改。上传前界面显示当前供应商，只有发送才向所选模型提供图片。

API 使用 Responses 的 input_image；Codex 登录使用 localImage。替换或清除图片时，Codex 会重建临时模型上下文并保留文字对话与精简场景回执，世界和设计卡不变。日志只记录图片元数据和耗时，不写入图像载荷或原始绝对路径。
