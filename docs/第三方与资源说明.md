# 第三方组件与资源来源

本项目未复制研究视频中的《艾尔登法环》资产、Smithbox 导出或 AIVA 曲目。白盒使用引擎基础网格，角色使用本机 UE 官方 Manny 模板。

| 组件 | 版本／来源 | 用途及许可 |
|---|---|---|
| Unreal Engine | 本机 UE 5.8.2 | 运行时游戏、官方基础网格与 Manny；适用用户的 Epic/Unreal Engine 许可 |
| CPython | UE 安装所附 Python 3.11.8 运行时 | 便携桌面运行环境；原始许可文件随运行时保留 |
| PySide6 / Qt | 6.10.2 | 桌面 UI；PySide6 元数据列出 LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only；各 Qt 模块的原始许可证保留在运行时包中 |
| Vosk API | 0.3.45，alphacep/vosk-api | 本地流式语音；上游 Apache 2.0 |
| 中文识别模型 | vosk-model-small-cn-0.22，官方模型页 | Apache 2.0；模型压缩包 SHA-256 记录于 `.local-assets/speech/manifest.json` |
| PyAudioWPatch | 0.2.12.8 | 麦克风与 WASAPI 回录；所装包元数据为 Apache-2.0，完整许可证随包保留 |
| NumPy | 2.2.6 | 离线节拍分析与验收信号处理；BSD 及所附组件许可见包内 LICENSE.txt |
| MCP Python SDK | 1.30.0 | 本地工具协议；MIT |
| HTTPX | 0.28.1 | 自定义供应商 Responses API 的可取消异步流式请求；BSD-3-Clause |
| Codex CLI | 本机已有安装和登录 | 对话模型宿主；不随包复制用户凭据，不创建第三方账户 |

资源：

- `tools/lc/assets/architect.svg`：本项目原创静态建筑助手立绘。
- `tools/lc/assets/levelcontrol.svg`：本项目原创客户端图标；构建时确定性渲染为 EXE 的 ICO 资源。
- `scripts/create_music.py` 与 `architect-pulse.wav`：本项目原创合成配乐，可由脚本重建。
- `architect-pulse.beats.json`：实际 PCM 分析结果，不是从研究视频抄录的节拍时间表。
- 验收语音：Windows 惠惠语音合成的本项目测试句，仅作为可重复的流式识别输入；不将它标为真人录音。

官方资料：[Vosk 模型与许可证](https://alphacephei.com/vosk/models)、[Vosk API](https://github.com/alphacep/vosk-api)、[Qt for Python 许可](https://doc.qt.io/qtforpython-6/licenses.html)、[Codex App Server](https://developers.openai.com/codex/app-server/)。

交付目录不复制用户的全局 `.codex` 配置、密钥或 `%LOCALAPPDATA%/LevelControl/model-settings.json`。现有 Codex 路线使用本机登录；自定义供应商路线直接使用用户配置的 API，不要求 Codex 登录。运行时生成的聊天诊断留在本地 Saved／tests/reports 目录。原生客户端嵌入随包 CPython，编译只需开发机的 MSVC x64 工具；使用发行包不要求另装 Python 或 Unreal Editor。
